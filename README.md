## Products

| Product | What it does |
| --- | --- |
| [Anti-Cheat](https://hcp-ac.com/anticheat) | Live FiveM protection, player management and evidence review. |
| [PC Analysis](https://hcp-ac.com/pc-analysis) | PIN-based Windows PC checks with structured reports. |
| [Complete](https://hcp-ac.com/pricing) | Anti-Cheat and PC Analysis with shared player context in the panel. |

## Anti-Cheat

- **Protection:** checks for suspicious aim, movement, menus and manipulation of server events, entities and resources.
- **Live Watch:** watch selected players and request screenshots or clips.
- **Player management:** review detections, manage bans and take player actions from the panel or in-game admin menu.
- **Resource protection:** installer integration for eligible server resources.
- **Discord integration:** check status, manage bans and look up players through the HCP public bot.

## PC Analysis

A staff member creates a scan PIN. The player enters it in the official download flow, opens the Windows scanner and accepts the analysis. Results are sent to the matching session in the panel.

- Checks relevant files, FiveM traces, running processes and available Windows metadata.
- Separates confirmed file matches, execution context and indicators that need review.
- Shows scan coverage so the team can see which sources were checked.

A file match alone does not establish execution. Review indicators and scores need staff assessment.
