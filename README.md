## About HCP AC

**HCP AC** is a security and analysis ecosystem developed for FiveM servers.

The platform combines real-time server protection, PC analysis, security databases,
license management and modern administration tools in one central system.

HCP AC provides server teams with clear indicators, reports and technical evidence.
Final moderation and ban decisions always remain with the responsible server team.

---

## Platform

| System | Description |
|---|---|
| **HCP Anti-Cheat** | Real-time FiveM protection with configurable detections, event monitoring and incident reporting. |
| **HCP Analytic** | Consent-based PC analysis and scanner system for identifying suspicious files, processes and activity. |
| **Intelligence Database** | Central database for flagged users, known cheating communities and security-related Discord information. |
| **Team Panel** | Web-based management for scans, incidents, licenses, users, roles and permissions. |
| **API & Integrations** | APIs, Discord integrations, webhooks and external server connections. |

## HCP Anti-Cheat

The HCP Anti-Cheat is designed to detect suspicious behavior directly on a FiveM server.

Core areas include:

- Event and trigger protection
- Suspicious player behavior detection
- Weapon and combat checks
- Resource and injection monitoring
- Configurable detection modules
- Incident and evidence logging
- Team bypass and permission management
- Central configuration through the HCP AC panel

The system is built to support server teams without replacing human moderation.

---

## HCP Analytic

HCP Analytic provides structured PC analysis for FiveM server teams.

The scanner can analyze relevant system areas such as:

- Running processes
- Downloads and temporary files
- FiveM files, modifications and caches
- Connected and previously used USB devices
- Browser-related indicators
- Recently accessed files
- Suspicious tools, loaders and bypass software

Results are classified as indicators and presented in a structured report.

---

## Security Intelligence

HCP AC maintains security-related databases that can support server teams during
player checks and moderation processes.

The platform separates different types of information:

- Confirmed blacklist entries
- Flagged Discord users
- Known cheating communities
- Server-specific user records
- Security incidents and reports

Flagged information alone is not treated as automatic proof of cheating.

---

## Team Management

The HCP AC panel provides centralized control over the entire platform.

Available management areas include:

- License administration
- Team members and permissions
- Scan and report management
- Anti-Cheat configuration
- Security incidents
- Discord integrations
- API access
- Webhook delivery
- System status and logs
