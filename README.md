# Platform

HCP AC is a FiveM security and analysis platform built for server teams that need more than a basic anti-cheat.

It connects live protection, player monitoring, evidence, player intelligence, browser-based administration and consent-based PC analysis in one management environment.

The goal is simple: give staff enough technical context to understand what happened, review evidence and make a decision without jumping between unrelated tools.

</td>
<td width="33%" valign="top">

</td>

# Why HCP AC

A detection alone rarely tells the full story.

HCP AC is designed around multiple layers of context:

```text
Live Protection
      |
      v
Player Activity + Detections
      |
      +--------------------+
      |                    |
      v                    v
   Evidence            Web Watch
      |                    |
      +---------+----------+
                |
                v
        Player Intelligence
                |
      +---------+----------+
      |                    |
      v                    v
 Trust Score          Check User
      |                    |
      +---------+----------+
                |
                v
         Manual Team Review
```

The platform keeps indicators, evidence and confirmed information separated wherever possible.

A flag can be useful context without automatically becoming a ban.

HCP Anti-Cheat is the live protection layer of the HCP platform.

It is designed to monitor suspicious behavior, protect server resources and events, collect evidence and make security information available to authorized team members through the web panel.

## Detection Context

HCP AC does not need to treat every single indicator as final proof.

Depending on the module, detections can be combined with:

- Player identifiers
- Current session information
- Previous incidents
- Ban history
- Screenshots
- Evidence clips
- Scanner context
- On-Screen Analysis context
- Trust information
- Team notes

This gives staff a better basis for manual moderation than an isolated console line.

# 24/7 Player Monitoring

HCP AC continuously monitors connected player and security activity while the FiveM server is online.

This layer is separate from visual Web Watch. The platform can keep player status, relevant detections, server activity and security context synchronized with the panel without requiring a staff member to manually watch every player at all times.

## Monitoring Overview

| Area | Purpose |
|---|---|
| Player status | Keep online and session state available to the panel |
| Security events | Surface relevant Anti-Cheat events and detections |
| Activity context | Associate security information with the correct player and session |
| Resource heartbeat | Show whether protected components are communicating correctly |
| Evidence context | Connect screenshots, clips and incidents to the player |
| Team visibility | Make current security state available from the browser |

> 24/7 Monitoring does not mean that every player's video feed is permanently recorded. Visual observation is handled separately through Web Watch.

## Important Distinction

A player appearing in a flagged Discord or community is not automatically treated as a confirmed cheater.

Community information can affect the context available to staff, but it remains separate from confirmed HCP records.

Strong or confirmed findings can carry more weight than weak or ambiguous indicators.

## Trust

# Security & Privacy

HCP AC is designed around controlled access, contextual evidence and transparent analysis workflows.

## Principles

- PC analysis requires the applicable user consent flow.
- Access is restricted through licenses and team permissions.
- Sensitive production systems remain private.
- Reports are available only to authorized team members.
- Contextual indicators are separated from confirmed evidence.
- Flagged information does not automatically become a ban.
- Security-relevant management actions can be logged.
- API access requires authorization.
- Enterprise webhook payloads can be signed.
- Temporary analysis data can be cleaned up after processing.

HCP AC provides technical security context. Final moderation decisions remain with the responsible server team.

# FAQ

<details>
<summary><strong>Is HCP AC only an Anti-Cheat?</strong></summary>

No. HCP AC combines live FiveM protection with player monitoring, evidence, player intelligence, browser management and optional PC analysis through HCP Analytic.

</details>

<details>
<summary><strong>What is the difference between 24/7 Monitoring and Web Watch?</strong></summary>

24/7 Monitoring refers to the continuous security and player context available while the server is running.

Web Watch is the visual browser-based review of selected players and is used when a staff member wants to directly observe a player.

</details>

<details>
<summary><strong>Does HCP AC permanently record every player?</strong></summary>

The platform description does not mean that every player is permanently video-recorded. Web Watch, screenshots and clips are separate evidence and review functions.

</details>

<details>
<summary><strong>Does a Discord flag automatically ban a player?</strong></summary>

No. Flagged community information is contextual. Confirmed HCP records are handled separately.

</details>

<details>
<summary><strong>Does a scanner finding automatically prove cheating?</strong></summary>

No. HCP Analytic is intended to provide technical indicators and structured context for staff review. Findings can have different confidence or severity levels.

</details>

<details>
<summary><strong>Can the Anti-Cheat be configured from the web?</strong></summary>

Yes. HCP AC provides browser-based configuration for supported Anti-Cheat settings, access controls and protection features.

</details>

<details>
<summary><strong>What is Trust Score?</strong></summary>

Trust Score combines available player context such as Anti-Cheat history, scanner context, On-Screen Analysis and security intelligence into one review signal.

</details>

<details>
<summary><strong>Can staff watch several players?</strong></summary>

Web Watch is designed around multi-player browser monitoring so authorized staff can select and review multiple players in the same workflow.

</details>

<details>
<summary><strong>Where are production downloads available?</strong></summary>

Authorized production downloads are provided through the official HCP AC platform and customer panel.

</details>
